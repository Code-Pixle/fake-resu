آوان ساخت | وب‌سایت نمونه معرفی سازنده

اجرا:
1) پوشه ZIP را Extract کنید.
2) فایل index.html را با مرورگر باز کنید.
3) برای نمایش کامل همه بخش‌ها، فایل index.html را از داخل همین پوشه باز کنید؛ پوشه assets باید کنار آن باقی بماند.

ساختار:
- index.html
- assets/css/style.css
- assets/js/main.js
- images/  (تمام تصاویر به‌صورت محلی داخل این پوشه هستند)

ویژگی‌ها:
- طراحی فارسی و راست‌چین، واکنش‌گرا
- فیلتر پروژه‌ها بر اساس نوع
- پنجره جزئیات هر پروژه
- منوی موبایل
- بدون نیاز به اینترنت یا CDN برای نمایش تصاویر، استایل و اسکریپت
- بدون درج شماره تماس، نشانی، شبکه اجتماعی یا راه ارتباطی

یادداشت مهم:
نام برند، نام پروژه‌ها، موقعیت‌ها، سال‌ها، متراژها و آمار این نسخه صرفاً اطلاعات نمونه برای نمایش قالب هستند و ادعای واقعی درباره یک سازنده یا پروژه مشخص محسوب نمی‌شوند. تصاویر نیز تصاویر تولیدشده برای همین قالب هستند. پیش از استفاده عمومی، اطلاعات نمونه را با اطلاعات واقعی جایگزین کنید.

تصاویر محلی این نمونه‌کار در پوشه images/ قرار دارند.
