سپهر املاک - نسخه نمایشی چندصفحه‌ای
====================================

اجرا:
1) فایل ZIP را کامل Extract کنید.
2) وارد پوشه sepehr-estate شوید.
3) فایل index.html را با مرورگر باز کنید.

صفحات:
- index.html       صفحه اصلی
- listings.html    فهرست فایل‌ها با جست‌وجو و فیلتر
- property.html    جزئیات ملک (شناسه در query string)
- favorites.html   ملک‌های ذخیره‌شده در مرورگر
- about.html       درباره سپهر
- services.html   خدمات
- contact.html    فرم درخواست

ویژگی‌ها:
- HTML / CSS / JavaScript خالص؛ بدون کتابخانه یا نیاز به اینترنت
- تصاویر محلی در assets/images
- جست‌وجوی عنوان، محله و کد ملک
- فیلتر نوع معامله، نوع ملک، محله، محدوده قیمت، حداقل متراژ و تعداد اتاق
- مرتب‌سازی بر اساس قیمت و متراژ
- ذخیره علاقه‌مندی‌ها با localStorage
- صفحه جزئیات پویا بر اساس شناسه ملک
- فرم‌های نمایشی با اعتبارسنجی سمت مرورگر
- طراحی واکنش‌گرا و راست‌چین

مهم:
این پروژه یک نمونه فرانت‌اند است. نام آگهی‌ها، تصاویر، نشانی محله‌ها، مشخصات و قیمت‌ها داده‌های نمونه هستند و آگهی واقعی یا قیمت روز بازار محسوب نمی‌شوند. قیمت‌های عددی صرفاً مقدار دقیق نمایشی برای تست رابط کاربری‌اند. قبل از انتشار عمومی، آن‌ها را با فایل‌های واقعی جایگزین کنید.
فرم‌ها به بک‌اند متصل نیستند. برای ذخیره/ارسال واقعی درخواست‌ها، پنل مدیریت، احراز هویت، مدیریت فایل‌ها و سرویس نقشه باید بک‌اند/API متصل شود.

تصاویر محلی این نمونه‌کار در پوشه images/ قرار دارند.
