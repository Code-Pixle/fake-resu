# یادداشت تصاویر Dood-o-Zafaron

در فایل `res/public/resum/dood-o-zafaron/index.html` تعداد ۱۱ تگ تصویر با آدرس خارجی باقی مانده است. طبق توافق، این تصاویر را دانلود یا جایگزین نکرده‌ام تا خودت فایل‌های مجاز/اختصاصی را قرار بدهی.

۷ تصویر محلی هم در `res/public/resum/dood-o-zafaron/images/` وجود دارد. برای حذف درخواست‌های خارجی، آدرس ۱۱ تصویر لینک‌دار را در همان `index.html` با مسیر فایل‌های محلی جایگزین کن. مجوز بازنشر تصاویر فعلیِ وب‌سایت‌های دیگر در فایل پروژه مشخص نشده است.
