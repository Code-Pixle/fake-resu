# تصاویر خارجی باقی‌مانده برای جایگزینی دستی

طبق درخواست، تصاویر دارای لینک خارجی دانلود یا تغییر داده نشده‌اند. برای حذف آخرین درخواست‌های تصویری خارجی، این موارد را خودت با فایل‌های مجاز/اختصاصی جایگزین کن.

## ۱) نمونه‌کار رستوران

- فایل کد: `public/resum/dood-o-zafaron/index.html`
- پوشه‌ی پیشنهادی برای قرار دادن تصاویر: `public/resum/dood-o-zafaron/images/`
- تعداد آدرس‌های خارجی: ۱۱
- تگ‌های تصویر در خطوط فعلی فایل: `188, 192, 196, 204, 212, 216, 220, 228, 236, 240, 248`

برای هر تصویر، فایل را داخل پوشه‌ی `images/` قرار بده و مقدار `src="https://..."` همان تگ را به مسیر محلی مانند `src="images/my-photo.jpg"` تغییر بده.

## ۲) نمونه‌کار فروشگاه لباس

- فایل کد: `public/resum/fashion-store/index.html`
- پوشه‌ی پیشنهادی برای قرار دادن تصویر: `public/resum/fashion-store/images/`
- تعداد آدرس‌های خارجی: ۱
- محل ارجاع: خط ۴۷، در آرایه‌ی `img` داخل داده‌ی محصولات؛ آخرین آدرس آرایه برای محصول دوازدهم استفاده می‌شود.

فایل تصویر جایگزین را داخل پوشه‌ی `images/` قرار بده و URL آخر آرایه را با مسیر محلی همان فایل عوض کن.

## وضعیت پس از جایگزینی

بعد از عوض کردن این ۱۲ آدرس و اجرای دوباره‌ی `npm run build`، از نظر کد پروژه دیگر نیازی به دریافت تصویر، فونت، CSS یا JavaScript از دامنه‌ی خارجی نخواهد بود. این گزارش فقط وابستگی‌های موجود در سورس را پوشش می‌دهد؛ سرویس‌دهنده‌ی هاست و تنظیمات DNS/TLS بیرون از کد پروژه هستند.
