# رزومه آنلاین طاها رودکرمی

رزومه‌ی سه‌زبانه با Vite، Tailwind CSS و JavaScript.

## اجرای نسخه‌ی توسعه

از داخل همین پوشه اجرا کن:

```bash
npm install
npm run dev
```

بعد آدرس محلی‌ای را که Vite در ترمینال نشان می‌دهد باز کن. فایل `index.html` را با دوبار کلیک و آدرس `file://` باز نکن؛ مرورگر ماژول‌های JavaScript را در این حالت درست بارگذاری نمی‌کند.

## انتشار روی هاست

محتویات پوشه‌ی `dist/` را داخل ریشه‌ی سایت (مثلاً `public_html`) آپلود کن؛ خود پوشه‌ی `dist` را داخل `public_html` قرار نده، مگر اینکه بخواهی سایت در آدرس `/dist/` نمایش داده شود.

برای تست محلی نسخه‌ی آماده:

```bash
python3 -m http.server 8000 --directory dist
```

سپس `http://localhost:8000` را باز کن.

## ویرایش اطلاعات و ترجمه‌ها

تمام متن‌ها و اطلاعات در فایل `src/data/content.js` قرار دارند. برای هر متن جدید، مقدار متناظر را در هر سه بخش `fa`، `en` و `ar` اضافه کن. کامنت‌های همان فایل محل افزودن هر مورد را مشخص می‌کنند.

- رندر بخش‌ها: `src/sections/render.js`
- انتخاب زبان، جهت صفحه، تم و منو: `src/main.js`
- استایل‌ها: `src/style.css`
- فونت فارسی و عربی: `public/fonts/`


## نمونه‌کارها
سایت‌های مستقل نمونه‌کار در `public/resum/` قرار دارند. راهنمای افزودن پروژه و ترجمه عنوان/توضیحات در فایل `PROJECTS-GUIDE.md` است.

## فونت‌ها و منابع محلی

فونت‌های اصلی و نمونه‌کارها از `public/fonts/` بارگذاری می‌شوند و برای نمایش متن به Google Fonts یا CDN نیاز ندارند. در دو نمونه‌کار کافه و رستوران، استفاده‌ی محدود از DM Sans به فونت سیستمی جایگزین شده تا درخواست خارجی لازم نباشد.

برای ساخت نسخه‌ی انتشار، از همین پوشه اجرا کن:

```bash
npm run build
```

محتویات `dist/` را روی هاست قرار بده. تصاویر دارای آدرس خارجی در این دو پوشه عمداً دست‌نخورده مانده‌اند تا خودت فایل‌های جایگزین را قرار بدهی:

- `public/resum/dood-o-zafaron/`
- `public/resum/fashion-store/`

گزارش‌ها و نشانی‌های منبع تصاویر محلی در `docs/image-sources/` هستند و در خروجی وب منتشر نمی‌شوند.

برای مسیر دقیق تصاویر خارجی باقی‌مانده و خطوطی که باید خودت عوض کنی، فایل `docs/EXTERNAL-IMAGES-TO-REPLACE.md` را ببین.
